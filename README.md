# Smart City Monitor

A smart-city environmental monitoring and analytics platform developed as part of my IT Capstone Project at Victoria University.

The project focuses on analysing and presenting environmental conditions such as air quality, noise, weather and traffic data to support easier monitoring and interpretation of urban conditions.

## Project Overview

Smart City Monitor was developed to explore how multiple environmental data sources can be combined into a single monitoring platform.

The project includes:

- Environmental data visualisation
- Air-quality monitoring
- Noise monitoring
- Weather-related information
- Traffic-related information
- Dashboard-based reporting
- Administrative and reporting interfaces

The project builds on earlier planning work completed in IT Capstone Project 1 and represents the implemented version developed in IT Capstone Project 2.

## Key Features

### Environmental Dashboard

The dashboard provides a central interface for viewing and comparing environmental information.

### Data Visualisation

Environmental measurements are presented through visual elements designed to make patterns and changes easier to understand.

### Reports

The reporting interface provides a structured way to review environmental information and analytical outputs.

### Administration

An administrative interface was developed to support management and monitoring functions within the application.
