Upload Instructions

CSV Format Requirements

  • First row must contain headers
  • For air quality: timestamp, site, PM2.5, NO₂, CO₂, temperature
  • For noise: timestamp, site, noise_level, frequency
  • For weather: timestamp, site, temperature, humidity, wind_speed
  • For traffic: timestamp, site, vehicle_count, average_speed
  • Timestamp format: YYYY-MM-DD HH:MM:SS

JSON Format Requirements

  • Must be an array of objects
  • Each object must have a timestamp field
  • Include all relevant measurement fields based on dataset type
  • Example: [{"timestamp": "2025-05-20 10:00:00", "PM2.5": 32, ...}]

Backend Integration

This system is now connected to a real backend!

  • Files are uploaded to: https://il4psjqi16.execute-api.us-east-1.amazonaws.com
  • Lambda function processes the file and validates data
  • Validated files are stored in AWS S3
  • S3 path is returned and displayed in upload history
  • All uploads are logged for audit trail
